# KodiKids - Petualangan Koding Anak SD 🤖⭐

Platform web edukasi koding dan computational thinking untuk siswa Sekolah Dasar (SD).
Karya untuk **M-ONE Telkomsel Coding Competition 2026** (Kategori Umum).

## 🚀 Fitur Utama
- Arena Koding Labirin 6x6 bujur sangkar (5 Level Tantangan Sekuensial)
- Karakter Robot Kodi dengan panah penunjuk arah putaran
- Modul 3 Jurus Logika Koding (Sekuens, Percabangan, Perulangan)
- Kuis Detektif Logika Cilik
- Fitur Tanya Kodi (AI Logic Assistant)
- Sertifikat Kelulusan Digital (Terbuka setelah 5 level tuntas)
